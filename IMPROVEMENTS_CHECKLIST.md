# План улучшений

- [x] **Preload-стратегия по расстоянию** — при скролле ленты каждое видео получает значение `preload` в зависимости от близости к активному: `auto` для текущего (полная загрузка), `metadata` для соседнего (только метаданные) и `none` для всех остальных (без загрузки), что экономит трафик и память..

- [x] **Единый `IntersectionObserver`** — `feedObserver.js`: один observer на все элементы с порогами `[0.25, 0.6, 0.9]`.

- [ ] **Виртуализация DOM** — рендерить только активный элемент + 1–2 буферных сверху/снизу. Радикальное снижение памяти. Сложность: средняя.

- [ ] **Инкрементальное обновление плееров** — `_applyPlaybackState` итерирует все плееры. Нужно обновлять только изменившиеся: `pause()` старого активного, `play()` нового, `setDistance()` только для ±2.

- [ ] **Делегирование событий** — один слушатель на `#feed` вместо 6 на каждый `VideoPlayer`. 100 × 6 = 600 замыканий.

- [ ] **Выгрузка далёких видео** — при distance ≥ 3 очищать `src` через `removeAttribute('src')` и сбрасывать состояние. Освобождение памяти.

- [ ] **CSS `content-visibility: auto`** на `.feed-item` с `contain-intrinsic-size: 100vh` — браузер пропускает рендеринг невидимых карточек.

- [ ] **Отложенная установка `src`** — сохранять `src` в `data-src`, устанавливать только при входе в буферную зону (±2). Снижает сетевую активность.

- [ ] **`aspect-ratio: 9/16`** — добавить на `.feed-video`, ограничить `.feed-item` по ширине (`max-width: 480px; margin-inline: auto`). Корректные пропорции на широких экранах.
