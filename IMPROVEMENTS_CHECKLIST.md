# План улучшений

- [x] **Виртуализация DOM** — рендерить только активный элемент + несколько соседних.

- [ ] **Инкрементальное обновление плееров** — `_applyPlaybackState` итерирует все плееры. Нужно обновлять только изменившиеся: `pause()` старого активного, `play()` нового, `setDistance()` только для ближайших.

- [x] **Preload по расстоянию** — при скролле ленты каждое видео получает значение `preload` в зависимости от близости к активному: `auto` для текущего (полная загрузка), `metadata` для соседнего (только метаданные) и `none` для всех остальных (без загрузки), что экономит трафик и память.

- [x] **Отложенная установка `src`** — сохранять `src` в `data-src`, устанавливать только при входе в буферную зону (±2). Снижает сетевую активность.

- [x] **Выгрузка далёких видео** — при проматывании очищать `src` отдаленных видео через `removeAttribute('src')` и сбрасывать состояние.

- [x] **Единый `IntersectionObserver`** — `feedObserver.js` - сделать один observer на все элементы, вместо отдельного на каждый.

- [ ] **Делегирование событий** — один слушатель на `#feed` вместо 6 на каждый `VideoPlayer`.

- [ ] **CSS `content-visibility: auto`** на `.feed-item` с `contain-intrinsic-size: 100vh` — браузер пропускает рендеринг невидимых карточек.

- [x] **Поправить пропорции на широких экранах** — добавить на `.feed-video` `aspect-ratio: 9/16`, ограничить `.feed-item` по ширине (`max-width: 480px; margin-inline: auto`).
